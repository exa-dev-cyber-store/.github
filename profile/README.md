### 🌟 Overview

**Cyber Store** adalah ekosistem e-commerce ritel berorientasi pengalaman premium bertema Apple Store. Sistem ini dibangun dengan backend Express.js & MongoDB, etalase web customer Next.js + Ant Design, back-office admin dashboard TanStack Query & Recharts, serta aplikasi mobile native Flutter dengan state management GetX.

---

### 🛍️ Core Ecosystem Repositories

| Repository | Tech Stack | Peran | Deskripsi Lengkap |
| :--- | :--- | :---: | :--- |
| [**`backend_store_apple`**](https://github.com/exa-dev-cyber-store/backend_store_apple) | Node.js, Express.js, TypeScript, **MongoDB (Mongoose)**, MinIO, Midtrans | Backend Core | REST API untuk autentikasi user, katalog produk Apple, payment gateway Midtrans, dan object storage MinIO untuk gambar produk. |
