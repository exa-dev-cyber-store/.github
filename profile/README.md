### 🌟 Overview

**Cyber Store** adalah ekosistem e-commerce ritel berorientasi pengalaman premium bertema Apple Store. Ekosistem ini menghubungkan backend transaksi terpadu, portal belanja web customer, dashboard operasional back-office admin, dan aplikasi mobile Flutter.

---

### 🛍️ Core Ecosystem Repositories

| Repository | Tech Stack | Peran | Deskripsi |
| :--- | :--- | :---: | :--- |
| [**`backend_store_apple`**](https://github.com/exa-dev-cyber-store/backend_store_apple) | TypeScript, Express, Prisma, PostgreSQL | Backend API | REST API inti untuk autentikasi, manajemen katalog produk, inventaris, dan transaksi pembayaran. |
| [**`apple_store_cyber`**](https://github.com/exa-dev-cyber-store/apple_store_cyber) | Next.js, TailwindCSS, TypeScript | Web Customer | Etalase digital responsif dengan desain estetika Apple, keranjang belanja dinamis, dan checkout mulus. |
| [**`dashboard_cyber`**](https://github.com/exa-dev-cyber-store/dashboard_cyber) | React, Vite, TailwindCSS | Admin Dashboard | Portal manajemen back-office untuk pemantauan penjualan, stok produk, dan status pesanan. |
| [**`cyber-mobile`**](https://github.com/exa-dev-cyber-store/cyber-mobile) | Flutter, Dart | Mobile App | Aplikasi belanja mobile native untuk perangkat Android dan iOS. |
